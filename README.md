# Допуски PRO · Precision Gauge

Мобильное offline-first PWA для расчёта предельных размеров деталей с произвольными верхними/нижними отклонениями из чертежа. Работает на GitHub Pages без бэкенда и тяжёлых JS-фреймворков.

**Открыть:** https://saitama21.github.io/Xiaomi-14T-APK/

## Precision Gauge Pro 2.0 — Graphite / Titanium

- Единая визуальная архитектура четырёх экранов: крупная приборная типографика, контрастные зоны ввода и результата, разгруженная история, обновлённая аналитика партии и информационные настройки.
- Полная тёмная Graphite и светлая Titanium темы, плюс режим «Система» со сменой при изменении настройки ОС. Прежние сохранённые темы и расчёты остаются совместимыми.
- Повышены размеры интерактивных элементов и поля ввода не уменьшаются ниже 16 px для предотвращения автоувеличения Safari.
- Переработана шкала допуска: деления, центр, отдельный маркер измерения, корректная подсветка выхода за границы и доступное текстовое описание.
- Dock остаётся прямым потомком body и неподвижно закреплён: `position:fixed;left:50%;transform:translateX(-50%);bottom:2px;width:87%;height:68px`.
- Без внешних шрифтов, тяжёлого фреймворка или изменений вычислительного ядра; сохранена автономная сборка GitHub Pages.

## Precision Gauge Pro 1.2 — контроль партии

- Новая вкладка «Партия» в существующем независимом dock (4 вкладки).
- Партия фиксирует допуск из текущего расчёта; до 20 локальных партий и 500 измерений в каждой.
- Запись фактических размеров с точностью 0,000001 мм; границы допуска включаются.
- Итоги: количество замеров, годных, брака, процент годности, фактические MIN/MAX и среднее.
- SVG-график последних 24 измерений: границы, целевой размер и подсветка брака.
- История четырёх последних измерений, отмена последнего, экспорт CSV и удаление партии с подтверждением.
- Хранение полностью на устройстве; при ошибке локального сохранения запись не считается успешной.
- Service Worker кеширует новые модули, расчётное ядро не изменено.

## Precision Gauge Pro 1.1 — удобство и контроль

- Smart Gauge: информативный индикатор выхода за пределы MIN/MAX, расстояние до ближайшего предела и состояние рядом с границами.
- Поле фактического замера **пустое при первом запуске**; сохранённые замеры пользователя не удаляются.
- Кнопки смены знака для отклонений, быстрое очищение замера, переход по Enter между доступными полями.
- Согласованные UI-токены, компактная адаптивная панель замера и уважение к настройке уменьшенного движения.
- Дополнительные UI-регрессионные проверки наравне с проверками арифметики.
- Сохранены CSS-геометрия и независимость fixed dock от app-shell и safe area.

## Возможности
- Размер и произвольные знаковые отклонения до шести цифр после запятой; точная целочисленная арифметика с шагом 0,000001 мм.
- Расчёт MIN/MAX/середины допуска, визуальная шкала диапазона и контроль фактического замера с включёнными границами.
- Справочный ISO 286 для полей **H/h**, квалитетов **IT5–IT12**, номиналы **0–500 мм**; числовые отклонения с чертежа всегда приоритетны.
- Архив 40 расчётов на устройстве (с постраничным просмотром), копирование, светлая/тёмная тема.
- PWA, offline после первой загрузки, iOS/Android Home Screen, самостоятельный фиксированный dock.

## Структура
- `index.html` — семантическая структура экрана.
- `src/styles.css` — адаптивные темы и layout.
- `src/core.js` — независимое математическое ядро.
- `src/app.js` — UI, сохранение и навигация.
- `sw.js` — service worker и автономный кеш.
- `tests/core.test.mjs` — регрессионные тесты, запускаемые перед публикацией.

## Тесты и публикация
`npm run check` проверяет JS и расчёты. `.github/workflows/pages.yml` запускает тесты и **только после их успеха** разворачивает GitHub Pages.

## Примечание
Центр поля допуска — начальная расчётная цель, а не готовая наладочная уставка: учитывайте износ инструмента, тепло, метрологию. Предупреждение «У границы» используется только как UX-индикатор внутри 10% от края поля, не меняет допустимые пределы. Обозначения посадок, кроме H/h, пока не рассчитываются автоматически.
