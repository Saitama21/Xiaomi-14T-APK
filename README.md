# Xiaomi 14T APK · Native Motion Lab

Нативная демонстрация возможностей Android на Kotlin + Jetpack Compose.

Автоматическая сборка: GitHub Actions → **Build Android APK** → Artifacts → `Xiaomi-14T-Motion-Lab-debug`.

Приложение работает офлайн; для установки используется debug APK. Обновление проекта будет происходить в этом репозитории.
