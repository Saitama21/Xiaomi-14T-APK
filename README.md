# Допуски PRO · Precision Gauge

Мобильное offline-first PWA для расчёта предельных размеров деталей с произвольными верхними/нижними отклонениями из чертежа. Работает на GitHub Pages без бэкенда и тяжёлых JS-фреймворков.

**Открыть:** https://saitama21.github.io/Xiaomi-14T-APK/

## Возможности
- Размер и произвольные знаковые отклонения до шести цифр после запятой; точная целочисленная арифметика с шагом 0,000001 мм.
- Расчёт MIN/MAX/середины допуска, визуальная шкала диапазона и контроль фактического замера с включёнными границами.
- Справочный ISO 286 для полей **H/h**, квалитетов **IT5–IT12**, номиналы **0–500 мм**; числовые отклонения с чертежа всегда приоритетны.
- Архив 40 расчётов на устройстве (с постраничным просмотром), копирование, светлая/тёмная тема.
- PWA, offline после первой загрузки, iOS/Android Home Screen, самостоятельный фиксированный dock.

## Структура
- `index.html` — семантическая структура экрана.
- `src/styles.css` — адаптивные темы и layout.
- `src/core.js` — независимое математическое ядро.
- `src/app.js` — UI, сохранение и навигация.
- `sw.js` — service worker и автономный кеш.
- `tests/core.test.mjs` — регрессионные тесты, запускаемые перед публикацией.

## Тесты и публикация
`npm run check` проверяет JS и расчёты. `.github/workflows/pages.yml` запускает тесты и **только после их успеха** разворачивает GitHub Pages.

## Примечание
Центр поля допуска — начальная расчётная цель, а не готовая наладочная уставка: учитывайте износ инструмента, тепло, метрологию. Предупреждение «У границы» используется только как UX-индикатор внутри 10% от края поля, не меняет допустимые пределы. Обозначения посадок, кроме H/h, пока не рассчитываются автоматически.
