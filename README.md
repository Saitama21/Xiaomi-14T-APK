# Допуски PRO

Полноценное офлайн-PWA для расчёта размеров деталей по чертежам на токарном и фрезерном ЧПУ. **Это веб-приложение, не Android APK.** Репозиторий полностью очищен от прежнего Android-проекта.

## Возможности
- Ввод произвольного номинального размера и верхнего/нижнего отклонения с чертежа (точка или запятая).
- Предельные размеры, середина и ширина допуска; вывод до 5 знаков после запятой при необходимости.
- Проверка фактического замера, включая включённые границы допуска.
- Табличный справочный режим ISO 286 только для H/h, IT5–IT12, номиналы от >0 до 500 мм.
- Локальная история, копирование расчёта, светлая/тёмная тема.
- Офлайн-кеширование страниц и ресурсов после первого онлайн-открытия. Без трекеров, серверов и зависимостей.

## Запуск и установка
GitHub Pages: https://saitama21.github.io/Xiaomi-14T-APK/

В **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions** (если ещё не выбрано). Workflow `.github/workflows/pages.yml` автоматически публикует корень ветки `main` после push.

На iPhone: открой HTTPS-ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить». На Android: открыть в Chrome → меню → «Установить приложение». Для офлайн-запуска сначала открой приложение при подключённом интернете.

**Важно:** Если на чертеже указаны числовые отклонения, считай именно по ним. ISO H/h служит справкой. Средина поля допуска — ориентир для наладки, не замена техпроцессу и контролю измерения.
