## Precision Gauge Pro 3.0 — Full Pro

Полная версия по утверждённому Graphite + Mint концепту: четыре рабочих экрана, точная цифровая шкала, контроль партий, журнал партий с фильтрами и инструментальные настройки.

- **Расчёт:** Smart Gauge с различимыми маркерами цели и факта; реальный запас до границ и статусы нормы, предупреждения и брака. Цель и разница выводятся без потери половины микрометра: например, Ø12 h6 → 11,9945 мм и при замере 11,994 мм разница −0,0005 мм.
- **Партия:** приоритет KPI, интерактивный SVG-график последних 24 измерений, выбранная точка и реальная статистика. Допуск фиксируется при создании партии; вычисления не изменены.
- **История:** фильтры по партиям «Все / Годные / С браком», дата, количество замеров, средний размер, переход обратно к партии; старые сохранённые расчёты доступны во второй вкладке.
- **Параметры:** компактные темы, status chip OFFLINE и архив JSON для резервного копирования и восстановления локальных партий, расчётов и темы.
- **Сохранение:** прежние localStorage ключи совместимы; архив перед восстановлением полностью валидируется. При ошибке записи предпринимается откат.
- **Offline-first:** стабильный ?v=3.0.0 для HTML-зависимостей JS/CSS и всех внутренних модулей; service worker precision-gauge-v11 кеширует полный согласованный граф и использует сетевой приоритет для изменяемых ресурсов.
- **Dock:** остаётся прямым ребёнком body и сохраняет точно position:fixed;left:50%;transform:translateX(-50%);bottom:2px;width:87%;height:68px. Safe-area используется только для отступов контента.

Автоматические проверки: целочисленная математика, импорт/экспорт, офлайн-зависимости, Responsive Chrome UI и отсутствие коллизий. Физическое iOS Safari тестирование требуется отдельно.

## Возможности
- Размер и произвольные знаковые отклонения до шести цифр после запятой; точная целочисленная арифметика с шагом 0,000001 мм.
- Расчёт MIN/MAX/середины допуска, визуальная шкала диапазона и контроль фактического замера с включёнными границами.
- Справочный ISO 286 для полей **H/h**, квалитетов **IT5–IT12**, номиналы **0–500 мм**; числовые отклонения с чертежа всегда приоритетны.
- Архив 40 расчётов на устройстве (с постраничным просмотром), копирование, светлая/тёмная тема.
- PWA, offline после первой загрузки, iOS/Android Home Screen, самостоятельный фиксированный dock.

## Структура

- `src/core.js` — независимое математическое ядро.

## Тесты и публикация
`npm run check` проверяет JS и расчёты. `.github/workflows/pages.yml` запускает тесты и **только после их успеха** разворачивает GitHub Pages.

## Примечание
Центр поля допуска — начальная расчётная цель, а не готовая наладочная уставка: учитывайте износ инструмента, тепло, метрологию. Предупреждение «У границы» используется только как UX-индикатор внутри 10% от края поля, не меняет допустимые пределы. Обозначения посадок, кроме H/h, пока не рассчитываются автоматически.
