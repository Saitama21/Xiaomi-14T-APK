# Допуски PRO

Независимый офлайн-калькулятор предельных размеров для обработки на ЧПУ. Существующий Kotlin/Android-проект в корне репозитория не изменён.

## Возможности
- Ввод любого номинала и верхнего/нижнего отклонения с чертежа (десятичная точка или запятая).
- Минимальный, максимальный и средний размер, ширина поля допуска.
- Проверка измеренного диаметра на попадание в допуск.
- Справочный режим ISO 286: поля H/h и квалитеты IT5–IT12 до 500 мм.
- Локальная история и светлая/тёмная тема.
- Service Worker для автономного запуска после первого посещения по HTTPS.

## Публикация
Веб-версия: `docs/tolerance-calc/index.html`. Для веб-адреса нужно включить GitHub Pages, публикуя `main` из папки `/docs`. После публикации путь будет `/Xiaomi-14T-APK/tolerance-calc/`.

Этот каталог — PWA, а не Android APK. GitHub Actions для сборки существующего Kotlin-приложения не изменён.

Обязательно используйте отклонения, указанные непосредственно на чертеже. Табличный ISO-расчёт не должен подменять размер, заданный конструктором.
