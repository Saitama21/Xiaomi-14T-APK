Как читать допуск

Номинал 25 мм, верхнее отклонение +0,05 мм, нижнее 0 мм означает, что деталь должна быть от 25,000 до 25,050 мм включительно.

Если обозначено ⌀35 h9, выбери режим ISO, тип h — вал и квалитет 9: от 34,938 до 35,000 мм.

Если на чертеже написано ⌀25 H9 без численных отклонений, таблица ISO даёт +0,052 / 0 мм. Если прямо написано +0,050 / 0 — введи эти значения вручную.

Стандартный режим ограничен полями H/h, а не всеми видами посадок (например, g6, k6, JS7). Для остальных используй числовые отклонения с чертежа.
